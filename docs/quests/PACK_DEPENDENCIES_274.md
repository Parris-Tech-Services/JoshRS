## Interpretation, and a correction made while measuring

My first pass classified npc/loc/obj *definitions* as VISIBLE and varps as BLOCKING. Both are
wrong: definitions and varps are text and can be imported by the tooling already in this repo.
The genuine cache wall is **models**, and this measurement finds **zero** model gaps among the 26
ported quests. What remains is mechanical import work plus interface registration.

**Nothing here has run in a world.** `npm run build` still fails, on animation names that the
importer can add but has not yet been driven to completion.
