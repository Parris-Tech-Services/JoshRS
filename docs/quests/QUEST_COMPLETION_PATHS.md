# Quest completion-path check

Generated by `tools/questops/check-completion-paths.mjs`.

A quest can have every file a structural audit looks for and still contain **no**
`send_quest_complete` call — meaning the player can do every step and never finish it.
This check tests only that a completion path exists and that its journal entry is real.

- quests checked: **64**
- with a completion path: **63**
- miniquests (no completion by design): **1**
- failures: **0**

## Failures

_None._

## Completion ids that do not match the directory name

Not errors — the journal entry is simply named differently — but worth knowing when
searching by directory.

- `quest_blackknight` → `questlist:fortress`
