# Zogre Flesh Eaters (16 May 2005)

JoshRS-original reconstruction. Start: the ogre guard at Jiggig (Grish has no cache NPC).
Chain: ogre guard (coffin key) -> oldest coffin (necromancy book) -> Zavistic Rarve
(Names Sithik Ints, gives transmogrification potion) -> inn assistant (Sithik's tea) ->
slip potion into tea -> give tea to Sithik (signed portrait) -> Zavistic Rarve.
Rewards: 1 QP, 2,000 Herblore XP.

Known gaps: the crypt exploration, the barbarian's backpack and the zombie ogre coffin loot
are not implemented. Stage values are JoshRS-original.
