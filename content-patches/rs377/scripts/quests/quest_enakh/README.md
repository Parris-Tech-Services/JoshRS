# quest_enakh - Enakhra's Lament (377)

JoshRS-original condensed reconstruction (released 2005-11-15, Members, 2 QP).

- Varp: `enakh_quest_expositbits` (cache varp, made permanent by the batch-5 patch).
- Start NPC: `enakh_lazim` (quarry south of the Bandit Camp).
- Chain: Lazim gives an `enakh_sandstone_large` block -> carve it with a `chisel` (`[opheld1]`) into two `enakh_sandstone_medium` -> Lazim builds the statue and asks you to push it (`enakh_lazim_statue_east_multinpc`) -> it sinks, revealing the temple -> the hooded one (`enakh_enakhra_hooded`) is Enakhra the Mahjarrat -> the bone guardian (`enakh_boneguard`) is really Akthanakos; wake it to break her binding -> complete, 2 QP.
- NOT IMPLEMENTED: the full statue puzzle, the bone guardian fight, the pentyn/faithful locations.
- Verified against npc.pack/obj.pack names; no opnpc1 collisions for the NPCs used.
