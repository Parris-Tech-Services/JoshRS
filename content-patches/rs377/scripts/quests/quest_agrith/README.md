# quest_agrith - Shadow of the Storm (377)

JoshRS-original condensed reconstruction (released 2005-09-05, Members, 1 QP).

- Varp: `agrith_quest_varp` (cache varp, made permanent by the batch-4 patch).
- Start NPC: `agrith_reen_alkharid` (Father Reen, outside the Al Kharid gates).
- Chain: Father Reen sends you to Father Badden (`agrith_reen_uzer`) at Uzer -> bring `silverlight` to be dyed black (`agrith_silverlight_dyed`) -> carve the `agrith_sigil` from the mould (`agrith_sigil_mould` + `silver_bar`) -> read the cult's `agrith_book` -> return with the black blade to break the ritual -> complete, 1 QP.
- NOT IMPLEMENTED: the Agrith-Naar summoning fight, clay golem, the cultist den.
- Verified against npc.pack/obj.pack names; no opnpc1 collisions for the NPCs used.
