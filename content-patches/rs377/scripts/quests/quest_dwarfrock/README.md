# Between a Rock... (14 March 2005)

JoshRS-original reconstruction. Start: Dondakan the dwarf in the Keldagrim south-east mine.
Chain: Dondakan -> Rolad -> boatman (archive plans) -> Rolad -> blast engineer (gold rock
helmet from 3 gold bars) -> Dondakan. Rewards: 2 QP, 5,000 Mining XP, 5,000 Defence XP.

Known gaps: the gold-vein wall scene, the cannon ride and the secondary mine entrance are not
implemented; the blast resolves through dialogue. Stage values are JoshRS-original.
