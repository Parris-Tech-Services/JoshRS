# One Small Favour (21 February 2005)

JoshRS-original reconstruction. Start: Yanni Salika in Shilo Village (hooked into his existing
antique-buyer handler by patch 0010). Chain: Yanni -> Seth Groats (axe) -> Tassie Slipcast
(cage, mahogany log from Johanhus Ulsbrecht) -> back to Seth -> back to Yanni -> Phantuwti
Far sight (weather report) -> Yanni. Rewards: 2 QP, 10,000 coins, key ring.

Known gaps: the full favour web (Brian Otrich, jungle forester, Captain Bleemadge, Santiri,
Hammerspike's gang, Petra's stone curse, gnome glider directionals) is condensed; no cache NPCs
exist for those characters. Stage values are JoshRS-original.
