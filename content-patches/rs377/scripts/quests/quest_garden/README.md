# quest_garden - Garden of Tranquillity (377)

JoshRS-original condensed reconstruction (released 2005-07-18, Members, 2 QP).

- Varp: `garden_varp_1` (cache varp, made permanent by the batch-4 patch).
- Start NPC: `queen_ellamaria` (Varrock Palace garden).
- Chain: Queen Ellamaria demands a royal rose garden -> a gardener (`misc_gardener`) gives white/red/pink rosebush seeds -> the queen takes the seeds once you have a `gardening_trowel` and `gardening_boots` -> plant with the `garden_trolley` NPC -> complete.
- NOT IMPLEMENTED: the full palace landscaping, ring of charos, farming patches.
- Verified against npc.pack/obj.pack names; no opnpc1 collisions for the NPCs used (stanford_the_gardener is owned by quest_murder, so misc_gardener was used instead).
